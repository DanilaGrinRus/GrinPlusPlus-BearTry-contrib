# Grin++ 2.0 — рабочий комплект

C++-нода Gplus (ветка `master`, коммит `302616f`) и десктопный UI (Tauri + React).
Версия: **Grin++ 2.0.0**.

## Состав
| Файл | Назначение |
|---|---|
| `GrinNode.exe` | нода (mainnet/floonet), PIBD, кошелёк-сервис |
| `tor\` | Tor-рантайм; должен лежать рядом с `GrinNode.exe` |
| `grinpp-desktop.exe` | UI (portable-запуск) |
| `Grin++_2.0.0_x64-setup.exe` | установщик UI (NSIS) |
| `Start Grin++.cmd` | portable-запуск UI из этой папки |
| `sources\` | исходники ноды и UI, из которых собран комплект |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |

## Запуск
1. **Portable (рекомендуется)**: запустить `Start Grin++.cmd` (или `grinpp-desktop.exe`).
   UI сам находит `GrinNode.exe` рядом, данные создаются в `.GrinPP\` этой папки.
2. **Установка**: запустить `Grin++_2.0.0_x64-setup.exe`; затем положить `GrinNode.exe`
   и `tor\` рядом с установленным `grinpp-desktop.exe` (или в подпапку `node\`).
3. В UI: раздел **«Нода»** → «Запустить». Сеть переключается в шапке (Mainnet/Floonet).
   Кошелёк: «Создать кошелёк» / «Восстановить кошелёк».

## Возможности
- Нода mainnet/floonet: синхронизация заголовков, блоков, txhashset; кошелёк-сервис.
- **PIBD** (0x10/0x40): приём state с горизонта и **раздача** своего архива
  (на mainnet — только при явном подтверждении `PIBD_ARCHIVE_SERVING_MAINNET=true`).
- **TX_KERNEL_HASH (0x08)**: запрос транзакции по kernel-hash (msgs 19/20).
- UI: статус с прогрессом/ETA, кошелёк (создание/восстановление, 12/18/24 слова,
  скрытие seed), отправка/приём (slatepack + QR), история с фильтрами, скрытие баланса.
- Управление нодой из UI: **Запустить / Стоп / Перезапустить**, переключение сети,
  **выключатель Tor** (`TOR.ENABLE_TOR` в `server_config.json`; применяется после рестарта).
- Логи по модулям (Node/Wallet/UI), фильтры, таймлайн этапов запуска.
- Языки: русский/английский. Настраиваемые порты (P2P 3414, REST 3413, wallet 3421).
- P2P: порт 3414; REST/wallet слушают только loopback; доступ к owner-API по `.api_secret`.

  Tor-выключателя); после изменения собрано и проверено live: Tor on/off, нода
  `FULLY_SYNCED`, кошелёк 3421, UI-контролы.

## Ограничения
- Tor-выключатель влияет на Tor-адреса/скрытые сервисы: при `ENABLE_TOR=false` они недоступны.
- Для приёма входящих P2P нужен открытый порт 3414 (NAT/firewall).
- Windows x64; исходники собираются по `sources\gplus-node-src.zip\BUILD.md`.

SHA-256 всех файлов — в `SHA256SUMS.txt`.
