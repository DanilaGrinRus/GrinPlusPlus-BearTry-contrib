## Root cause fixed during the run

The first attempts repeatedly failed just before completion:

```text
TxHashSetErr: missing left sibling in tree, should not have been pruned
PIBD Reported Failure - Restarting Sync
Validation of incoming output segment failed: idx 1648
Validation of incoming rangeproof segment failed: idx 1532/1533
```

The C++ segment generator omitted leaf data that was present in the backend
when the bitmap marked the leaf as spent. Rust `Segment::from_pmmr` sends such
data and expects the receiver to remove it from the leaf set. Omitting it left
a hole in the sequential PMMR.

Fixes:

- `SegmentGenerator` now sends available leaf data even when the bitmap bit is
  clear (matching Rust `Segment::from_pmmr`).
- `PibdTreeAssembler` filters received leaf data by the bitmap before
  publishing the unspent set.
- Regression tests cover compact source, available-data inclusion, and the
  fully pruned proof path.
