# P2P: что нужно сделать пользователю

## По умолчанию ничего не нужно
Нода сама устанавливает **исходящие** соединения на TCP 3414 и синхронизируется.
Кошелёк, платежи, приём/отправка работают без проброса портов.

## Когда нужны действия
Только если хочешь, чтобы **к твоей ноде подключались снаружи**:
- публичная нода;
- раздача PIBD незнакомым пирам;
- больше входящих пиров и устойчивость.

## Шаг 1. Windows Firewall (обязательно для входящих)
Запусти **`enable-p2p-firewall.cmd` от администратора** (правый клик → «Запуск от имени администратора»).
Или вручную в PowerShell от администратора:

```powershell
netsh advfirewall firewall add rule name="GrinP2P" dir=in action=allow protocol=TCP localport=3414
```

## Шаг 2. Проброс порта на роутере
В роутере (например T626Pro: NAT / Port Forwarding / Virtual Server):

| Параметр | Значение |
|---|---|
| Внешний порт | TCP 3414 |
| Внутренний IP | IP твоего ПК (например 192.168.1.33) |
| Внутренний порт | TCP 3414 |

Желательно закрепить IP за ПК (DHCP reservation) или настроить статический адрес.

## Шаг 3. Проверка
С другой сети (телефон/другой интернет) или через canyouseeme.org:

```powershell
Test-NetConnection <твой-публичный-IP> -Port 3414
```

Проверка со своего же NAT часто даёт `False` — это нормально.

## Несколько нод на одном ПК/сети
У каждой ноды свой P2P-порт: 3414, 3416, 3418…
- в `server_config.json`: `"P2P": { "P2P_PORT": 3416 }`;
- отдельное правило firewall и отдельный проброс для каждого порта;
- REST тоже развести (3413, 3415…), но REST **наружу не открывать**.

## PIBD-раздача (только если реально нужна)
По умолчанию нода только принимает PIBD. Чтобы **раздавать** свой архив на mainnet,
нужно явное подтверждение в `.GrinPP\MAINNET\server_config.json`:

```json
"P2P": {
  "PIBD_ARCHIVE_SERVING": true,
  "PIBD_ARCHIVE_SERVING_MAINNET": true
}
```

Раздача начнётся после готовности архива (после полного синка/валидации).

## Tor
Для обычного P2P **не обязателен**. Если сеть блокирует Tor — выключи тумблером
«Использовать Tor» в разделе «Нода» (или `"TOR": { "ENABLE_TOR": false }`), синк по IP продолжит работать.
Tor нужен только для `.onion`-адресов/скрытых сервисов.

## Что НЕ надо открывать
- REST **3413** и wallet **3421** — они слушают только loopback; наружу их выставлять не нужно.
- `.api_secret`, seed-фразу, кошелёк — никому не передавать.

## Если за CGNAT
Проброс не сработает (провайдер не даёт входящий публичный IP). Нода продолжит работать
исходящими соединениями — для кошелька этого достаточно.

## Диагностика
- `netstat -ano | findstr :3414` — порт слушается?
- В логах ноды: `P2P acceptor bound on port 3414`.
- Порт открыт снаружи, но пиров мало — проверь firewall/роутер и что нода запущена.
